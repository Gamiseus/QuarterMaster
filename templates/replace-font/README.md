# Example Mod

A replaced font for Mud and Blood.

1. Pick a font you are allowed to share (many fonts with the SIL Open Font Licence are).
2. Save it as `assets/fonts/impact.ttf` to take the place of the game's `impact.ttf`, the font
   of most of the game's text. `.otf` files work too.
3. Start the game: the new font is used wherever the game used the old one.

The modding wiki, Part 2: https://gamiseus.github.io/wiki/replacing-art-and-sound/#folders
