# Example Mod

A short description of the mod for players: what it changes and how to use it. This file is
the mod's page on the QuarterMaster site.

## Installing

Install it from the launcher's Browse tab, or download `ExampleMod.zip` from the releases and
add it with the launcher's Add mod button.

## Needs

[QuarterMaster](https://gamiseus.github.io/) for Mud and Blood.
